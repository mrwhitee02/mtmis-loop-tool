🔑 Captcha — aik dafa yahan paste karo

Ye 3 values dono loops (number loop + date loop) khud use karenge — har loop ke liye dobara paste nahi karna. Captcha expire ho to neeche "Fresh Captcha Lao" dabao — naya captcha yahin aa jaye ga, sirf image wala number type karo.

🔢 Number Loop — registration number ke zariye

Pehla aur aakhri number do — prefix (jaise RNO-17-) khud constant rahega, sirf serial badlega. Date neeche wali field se sab numbers par wohi lagegi.

📅 Date Loop — date ko loop karna ho to

Registration number fix daalo, aur starting/ending year do — us saal ki har date check hogi, pehla found milte hi loop ruk jayega.
